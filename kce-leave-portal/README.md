# KCE Student Leave Request Portal (Java + Spring Boot + MongoDB Atlas)

## To run
1. Open src/main/resources/application.properties and replace YOUR_PASSWORD with your Atlas password. Save.
2. In Atlas: Network Access -> allow 0.0.0.0/0.
3. Run KceLeavePortalApplication.java (VS Code Run button).
4. Open http://localhost:8080
